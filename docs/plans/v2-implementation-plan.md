# 实施依赖与放行条件

## 2026-11-20 后续优先级

| 顺序 | 工作及完成条件 |
| --- | --- |
| P0 本轮 | 最终作品人工验收。含必需人工项的工单必须签收，其他新单在批准时可选择人工签收。复用原工单、已批准预算与独立验收归档。双端显示作品版次、文件与摘要，以及自动检查结果。本人可签收，或注明原因退回。修复后产生新候选并重新检查。保留两次决定与归档，拒绝过期卡片和并发的第二个决定。旧单维持原契约。用一张真实工单验证退回、修改、重新验收和结案。 |
| P1 | 为交互网页、服务 API 等补独立验收。以正确和有缺陷的产物对照检验误放行，再扩展目录。 |
| P1 | 用陌生多阶段目标实测交付率、澄清质量和人工介入次数；据此实现普通返工与跨阶段协调分流。 |
| 发布前 | 生产恢复与回滚演练、部署依赖和面向他人分发的许可清单。 |
| P2 | 将同单拆包与 V2 接单衔接，实测真实模型并发；评估原生子 Agent 的成本与质量收益。 |

本轮决定绑定同一工单的目标、验收、授权、派工与交付检查点。签收人能下载该次已归档的字节。退回意见进入原授权内的修复任务；扩大目标或权限走已有改版流程。自动检查失败仍走现有失败处理，人工签收不能覆盖机器失败。
