## 故障、处置和复验

| 观察到的问题 | 处置及证据 |
| --- | --- |
| 原先选定的回环端口已占用 | 检索复跑支持系统分配的空闲端口。在独立实例完成四次派工。 |
| 原生事件 detail 接受字符串 | 来源插件将受限元数据编码为 JSON 字符串，接单端核对来源、事件类型和固定 SHA。实际 Hub 收到并派发。 |
| 文件还在写入时会被发现 | 合并投放事件，等待大小和修改时间稳定，scan 使用写稳窗口。扫描期间目录再变化就等待下一轮。分段写入试验首次派工零次。 |
| 缺少许可的材料也能出现在待处理列表 | scan 可在本机交付初读。派工与领取分别核对许可，AFR CLI 再检查固定版本。缺许可的对照只生成初读，Hub 没有第二次派工。正式纯本地配置另可强制 local_only。 |
| 文件已生成时，试点启动器抢先退出 | 启动器改为等待 Hub 持久回执，先确认 Hub 就绪再启动 Worker。在同一外投实例恢复了已落盘的回执，run 1 仍是首次 published，重派次数为零。更新后的启动器在新隔离库完整复跑退出 0。 |
| AFR 首版合成卡面摘要遗漏关键数值 | AFR 侧修订摘要生成并用相同合成文重新运行真实模型。独立读回新版 Canvas，卡面包含 10 个机柜、7 个已上架、70% 和复核 3 个空置机柜。UI 计时保留首次试验原值。 |
| AFR 验收设计连续两次超过默认 45 秒 | 工单保留失败调用，试点使用可设置的 100 秒有界时限重试。默认保持 45 秒。 |
| 模型把页面忠实性记作执行权限，又把已强制的写入边界列成验证缺口 | 原单区分权限与逐行人工核对条件。验收设计快照增加引擎已经强制的权限映射，权限仍由引擎校验。保留过往各版契约，当前版正常批准。 |
| 初次导出的两条 ok 记录难以判断哪条是修改前的命中 | 执行器停止生成，Run 10 报缺文件。导出器从真实来源事件补充已登记场景名，另行提供补充回执，保留最初的归档。 |
| 首次协调把只读规划会话误认为实施无写权限 | 增加各阶段实际沙箱映射、最近实施说明与本工单的脱敏补充资料。原单暂停、续办后 Run 12 选择修复，Run 13 生成页面，Run 16 完成最终检查。 |
| 扩展模型输入时破坏既有调用参数形状 | 完整回归捕获 6 个错误和 1 个失败。权限表移入既有工单上下文；复跑覆盖规划、重规划、实施、修复、审核和本机模型代理。 |
| 飞书侧不能以用户身份发起当次签收试验 | 在参观须知工单记录受阻的入口、网页版真实操作、飞书的真实发卡与官方回读。[双端签收问题记录](artifact-signoff.md) |
| 真实研报的模型出站未获批准 | 五份实际材料的外发请求被自动审批拒绝。本次 Autoloop 联调只对合成版本调用模型，正式材料可先本机处理。 |

## 日常运行与回退

文件观察器首次启动即补扫，此后按变化与恢复周期调用 AFR scan。可在配置中指定 legacy_db 以只读方式匹配已有资料。纯本地运行设置 local_only 为 true，不需要为观察器提供 Hub 签名密钥。停止观察器只停止新投放的处理，已生成的笔记、原文与固定版本可继续在 Obsidian 中阅读。看板查询需指定 AFR 程序、解释器和本人知识库，不设置时原看板照常运行。签收试点和正式环境分别配置。

跨文章比较、新话题决策及将讨论写回个人笔记仍由 AFR 产品项目按阶段验收。这次覆盖本地投放、检索、固定版读回、单篇白板和 Autoloop 工单验收。

对照本机 Hub 账本逐轮核验了回执和工单号，逐段校验版本摘要及逐条引用是否包含在来源中。两份 Canvas 的节点、连线及固定原文文件均已核对，两次下载字节与归档相同。导出操作将原件复制到既有 Obsidian 试点库，保留相对引用，遇到用户修改的同名文件会中止。当前端口实际返回前端页面及脚本；Chrome 控制连接不可用，本轮未代替用户进行图形界面点击或签收。

独立检查发现三类问题：追问最初丢失上轮开放问题，已为每单历史加入本机完整性校验再传入模型；枚举后路径变更可能使读取离开资料库，改为逐级按目录描述符读取；不完整样本可能被表述为全量，现由代码独立记录实读、未读、跳过与扫描上限。覆盖数字能核对阅读范围，引用匹配只能证明原文包含这段文字，不能单独证明概括忠实或结论正确。

离线默认路径可遍历和摘录；本机系统模型可用性探针返回 deviceNotEligible，目前没有真实离线模型综合的验收。受控研究试点的真实模型调用使用固定合成材料，正式研报的模型外发保持关闭。按真正入库时间汇总正式全库、长期自动路由和跨单记忆均未在该试点验收。

复核追问轨迹时发现，早期搜索只展示未读候选，已经读过的来源即使匹配也不会出现在候选里。现已让关键词搜索返回匹配的旧来源；本地回归用前一轮的资料连续搜索「报价」「误报」，两个查询均命中并可再次固定版读回。该用例使用受控的模型动作替身；上表保留真实模型当时的动作。验收通知脚本首次因分支语法错误未发送，修正后正式工单返回 saved。后台托管限当前登录会话，未验证重启电脑后的自动恢复。

验收时本人在正式工作台批准 v1。主执行器读取第一批交付后要求补充原生证据，工单保留这次阻塞。随后向同单交付了四组 run/event 的原生账本字段、Worker 启停记录、四份合成请求、七份源文件、独立签名复核与两份阅读稿。历史运行没有记录逐段墙钟时间，已在补充材料中注明。本次候选回归合计 282 项通过，含真实 macOS Seatbelt，研究方案与看板新增覆盖 15 项。工作台完整签收状态以本单最新决定为准。
