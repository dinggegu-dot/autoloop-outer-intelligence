# 王国地图与双端工单验收

本轮复用此前本人飞书私聊的温度换算测试单。在隔离副本中查看既有交付和模型调用，再用原工单测试修改。正式发布仍须单独决定。

| 环节 | 操作与观察 |
| --- | --- |
| 原版画册 | 在正式 Chrome 打开王国封面。保留原星球、飞艇、角色、明信片和十站航线。切到都市国近景可看到楼体四面的窗带，切回全景可继续换站。390 × 844 视口复查了星球、工单卡、操作按钮和可横向浏览的路线。 |
| 独立下载版 | 单独启动无画册、无 Hub 账户的实例。Chrome 可打开王国图鉴和自绘星球，十个地标有独立明信片与入口。 |
| 桌面工单 | 从地图的角色调用站直达同单历史。在本次修改之前的副本核实六条记录和协调器明细，修改后的副本显示八次真实调用。新增两条接单判断分别耗时 45,078 ms 与 45,063 ms，展开后一条可看到 timeout。原单仍显示两个温度样例 PASS 与文件下载入口。 |
| 飞书客户端 | 在已授权的本人私聊点击目录中的原单、修改要求与指定替换项，回复测试文字并收到收件回执。独立试点和旧桥同用一个机器人，投递幂等键现在可按试验前缀区分。 |
| 修改失败 | Intake Assessor 连续两次超时，这条修改事件进入 NEEDS_ATTENTION。原工单 v6、目标 v2、验收 v2 和既有文件保留。试验发现旧桥接投影会把此前的完成结果重复发送。候选回归覆盖新版失败卡，另以同一私聊的一条文字回执更正误报，飞书服务端确认接收。 |
| 新版批准 | 本轮没有产生可供批准的新契约。用隔离样本检查了待批准卡的工单版本、目标版本、验收版本、模型、预算、允许操作、限制和两条检查的实际渲染字段。此前真实批准及交付保存在另一次运行的证据中。 |
