# 目标漫游局 · 双端工单改版

打开原来的「工单工作台」，先看「待我决定」。例如，一张普通工单需要批准、另一张团队工单已经交付时，可以从首页直接进入第一张的审批位置，也可以打开第二张的交付文件。长报告在选中工单后阅读，收起详情即可继续选单。

桌面沿用现有的凯皮、王国地图和工单控件。团队工单详情提供返回首页的入口。首页保留全部待办，正在推进和已交付的团队工单各预览三张，超出时可进入对应分组查看全部。本人飞书私聊沿用原卡处理。长期建设见[架构依据](../architecture/architecture-alignment.md)。

| 路径 | 产品决定 | 验收依据 |
| --- | --- | --- |
| 地图与队列 | 采用原「目标漫游局」的全屏王国封面、十站航线与明信片。星球支持旋转、回正和地标近景。王国入口指向当前工单的对应内容，列表支持按决定、执行、交付和停靠筛选。 | 空队列显示零；同单修订保留身份；窄屏可用键盘和按钮进入详情。 |
| 发布与修改 | 发布目标进入原接单队列。详情提供当前要求、验收、修改及替换绑定；正式执行和交付继续关联同一工单。 | 查看与切单零模型调用；修改绑定当前版本；深链接及轮询不串单。 |
| 复杂任务需决定 | 首屏呈现需要决定的事项、触发原因、影响或缺失证据及下一步。授权前可核对范围、验收和预算。 | 选单、澄清、批准、缺口和协调请求区分显示；模型建议不取得授权。 |
| 飞书 | 私聊发目标；目录用目标名称找回；原卡呈现当前决定、版本和可操作入口。 | 新旧卡、重复点击、原卡修改及一端操作后的另一端状态用已有桥和会话验证。 |
| GitHub 下载 | 发行版自带原创地形和航标，无需在线地图素材；README 给出功能结构、真实依赖、试点启动、验证、复用及局限。 | 用仓库文件启动并打开页面；仓库检查与双端回归通过。 |

原版构图、标题、航线与星球交互来自现有工作台。原工作区可继续使用已有画册，发行包提供自绘纹理、明信片、飞艇和十组微缩地标。两种显示方式共用入口及工单投影。便携版的 Three.js r180 组件和 MIT 声明随库提供。素材选择及复用方式见[项目首页](../../README.md)。

工单状态取自工单版本和已记录的执行结果。地图十站是同一工单的功能入口，月亮计数统计已交付工单，翻看地标不改变任何业务进度。用户切换筛选可选择新单，后台刷新时保留已经打开的工单。
