# 看板本机 AFR 查询

先将 AFR v1 命令适配纳入同一版本。运行网页工作台时，加下面三个同属一个已选知识库的绝对路径参数。

    python3 -B 网页工作台/server.py --port 8765 --runtime /private/tmp/your-board-runtime \
      --afr-root "$AFR_ROOT" --afr-python "$AFR_PYTHON" --afr-vault "$AFR_VAULT"

已有隔离看板也可以在原启动命令追加三个参数。看板导航增加「AFR 本机查询」，直接入口为 http://127.0.0.1:8765/afr。未配置的实例不会显示入口或启用相关接口。工作台当前工单和独立查询页没有数据关联。

搜索结果显示文件相对路径和章节标题。选中后按 ref 与 revision 回读正文并核对内容摘要。文件此时已有改动则须重新搜索。请求与正文仅经过本机同源工作台会话，不进入工单、调度履历或模型请求。

故障检查使用新建私有运行目录和合成知识库。正常 HTTP 验收需实际验证会话、CSRF、搜索/原文读取、无命中、旧 revision 拒绝和未启用实例的 404 行为。
