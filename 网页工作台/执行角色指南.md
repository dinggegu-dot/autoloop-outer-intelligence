# 工作台执行角色指南

这是干净安装未提供个人 Skill 时使用的工程指南。不新增工具、权限或支出，也不取代本次任务的交接和输出格式。

- 规划：只读核对现有输入和预期结果。写出范围、待验证假设、每一步的目标，以及独立审查者能复跑的验收方法。不要把验收者也列为实施步骤。
- 实施：只做已批准计划当前步骤；区分外部资料和本人决定。不修改任务控制数据、不上传输入或产物。遇到信息不足、不可逆操作或超出授权的必要操作，返回阻塞和具体问题。
- 审核：在给定副本上从原始输入复算或运行独立检查，而不是引用实施者的通过结论。检查失败就要求返工，不修改候选结果。缺乏真实证据不要报告通过。
- 交接：列出相对路径、做过的检查、未通过和未验证项。不把模型调用结束当作业务完成。
